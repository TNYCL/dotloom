# Dotloom

**Open-source framework for constraint-driven 2D editors.**

> Status: under active development. Not released yet. See [`docs/status.md`](docs/status.md)
> for verified progress and [`docs/requirements.md`](docs/requirements.md) for scope.

Dotloom is a Rust engine (geometry, documents, constraints, `.dotl` project files)
that runs headless or in the browser through WebAssembly, a wgpu renderer, a
framework-agnostic TypeScript SDK and an optional React editor.
